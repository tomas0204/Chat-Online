# 💬 Chat Online con WebSockets (En Desarrollo)

Este proyecto es una aplicación de chat en tiempo real desarrollada con **Django** y **Python**, utilizando **WebSockets** para la comunicación instantánea entre usuarios.

⚠️ **Estado:** En desarrollo (Work in Progress)

---

## 🚀 Descripción

La idea de este proyecto es construir un sistema de chat moderno, eficiente y escalable que permita la comunicación en tiempo real sin necesidad de recargar la página.

Este proyecto forma parte de mi **portfolio como desarrollador**, por lo que iré incorporando mejoras, optimizaciones y nuevas funcionalidades con el tiempo.

---

## 🛠️ Tecnologías utilizadas

* **Python**
* **Django**
* **Django Channels (WebSockets)**
* **HTML / CSS / JavaScript**
* *(Base de datos aún por definir)*
